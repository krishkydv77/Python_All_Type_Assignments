# 🎓 Student Management System - Python

A command-line based Student Management System built using Python and Object-Oriented Programming (OOP) concepts.

This project allows users to perform CRUD operations such as adding, viewing, and deleting student records using a modular architecture with models and service layers.



#  Features

* Add new students
* View all student records
* Delete student records
* Menu-driven CLI application
* Object-Oriented Programming implementation
* Modular project structure
* Service layer architecture



#  Tech Stack

* Python
* OOP (Object-Oriented Programming)
* CLI (Command Line Interface)



#  Functionalities

## 1. Add Student

Users can add:

* Student ID
* Name
* Age
* Course
* Email

## 2. View Students

Displays all stored student records.

## 3. Delete Student

Delete student data using Student ID.

---



#  Sample Menu


1. Press 1 to add Student
2. Press 2 to View all the students
3. Press 3 to delete student
4. Press 4 to exit
